# EasyNavi - 现代极简浏览器启动页

> 基于**第一性原理**与**复利设计思维**打造的纯前端蓝白极简导航页。零后端依赖，纯静态直出，全键盘快速直达。

---

## 特性

### 1. 蓝白极简美学与背景系统
- **纯净蓝白主题**：默认纯白画布搭配无边框高通透卡片与聚光灯微高光反馈，彻底隐藏冗余简介与弹窗按钮。
- **Zen 沉浸视窗模式**：按 <kbd>Space</kbd> 或双击页面空白处，前景工作台淡出、背景遮罩退隐为 0；按 <kbd>Esc</kbd> 或 <kbd>Space</kbd> 恢复。
- **自定义图片背景**：支持图片链接与本地图片上传（持久化于浏览器 IndexedDB），提供实时遮罩浓度、毛玻璃模糊度与视差位移调节。

### 2. 应用级图标网格与物理拖拽排序
- **自适应密度网格**：支持紧凑（3~8 列）、标准（3~6 列）、宽松（2~5 列）及三档分类间距；未悬停时自动收敛为首排单行，悬停后沿贝塞尔卷轴展开全部卡片。
- **Pointer 物理滞回拖拽**：长按卡片或通过右键菜单进入调整模式，支持 6px 起拖死区、40%/60% 滞回区间防抖与跨分类拖放排序。
- **本地微图标管线**：支持在添加弹窗或表格视图中上传图片、拖拽图片或直接粘贴剪贴板截图（<kbd>Ctrl</kbd>+<kbd>V</kbd>），通过原生 Canvas 居中重采样为 128px PNG DataURL（小体积 SVG 直接保真内联）。
- **分层图标策略**：优先读取本地内联 DataURL 与 IndexedDB 内存预热缓存；未显式配置图标时优先匹配内置 Homelab 特征库，内网地址仅探测同源 `favicon.ico`（不外发内网拓扑），公网地址回退至 `icon.horse`。

### 3. 全键盘盲打流、拼音检索与 Bang 路由
- **统一评分与拼音检索**：支持标题、Clean URL 域名、描述、分类名、多关键词空格分词、汉字全拼与首字母匹配，并结合点击频次加权排序。
- **书签联想与网格漫游**：输入时同步提供最多 5 条书签联想（<kbd>↑</kbd>/<kbd>↓</kbd> 遍历，<kbd>Tab</kbd> 回填，<kbd>Enter</kbd> 打开）与网格卡片高亮直达。
- **Bang 快捷语法与网址直达**：输入 `g <词>` 跳 Google、`b <词>` 跳 B站、`gh <词>` 跳 GitHub、`bd <词>` 跳百度、`bi <词>` 跳 Bing、`ddg <词>` 跳 DuckDuckGo；输入域名或 IP/localhost 时直接访问目标网址。

### 4. 纯前端持久化与批量管理
- **零数据库依赖**：配置实时保存至浏览器 `localStorage`，支持标准 JSON 导入导出与一键恢复默认模板。
- **结构化站点管理表**：按 <kbd>J</kbd> 打开表格视图，支持站内检索、多选批量修改分类/删除、行内置顶、下拉新建/删除分类及未填完防呆校验。
- **PWA 离线可用**：内置 Web App Manifest 与 Workbox Service Worker（生产环境自动注册）。

### 5. 快捷键与手势
- <kbd>/</kbd> 聚焦搜索框
- <kbd>↓</kbd> / <kbd>↑</kbd> / <kbd>Tab</kbd> 遍历书签联想或匹配卡片
- <kbd>Enter</kbd> 打开选中项 / 访问直达网址 / 执行搜索
- <kbd>Space</kbd> 切换 Zen 沉浸模式（或双击页面空白处）
- <kbd>N</kbd> 添加站点
- <kbd>J</kbd> 打开站点管理表格
- <kbd>?</kbd> 查看快捷键指南
- <kbd>右键</kbd> 呼出卡片管理菜单
- <kbd>Esc</kbd> 关闭浮层 / 退出调整或沉浸模式

## 配置文件 (`public/nav.json`)

仓库内置的 [public/nav.json](public/nav.json) 为脱敏示例骨架，个人私有配置建议在页面内导入导出管理；如需本地私有备份可保存为 `nav.local.backup.json`（已被 `.gitignore` 忽略）。

## 开发、测试与构建

```bash
# 安装依赖
pnpm install

# 启动开发服务器 (支持局域网访问，端口 5188)
pnpm dev

# 运行单元测试
pnpm test

# 类型检查与生产构建
pnpm build
```
